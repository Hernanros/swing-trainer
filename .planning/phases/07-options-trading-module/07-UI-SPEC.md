## Component Inventory

### 1. Advisory Panel (new, inside TradeDrawer)

**Location in render tree:** Immediately after the `optionMetrics` display block
(after the 3-column max-risk/max-profit/breakeven grid), before the pre-note textarea.
Only renders when `form.trade_type === 'option_spread'` AND `mode === 'open'`.

**Visibility condition:** Always shown when in option_spread open-mode (even before
fields are filled). The "Get Advisory" button is disabled until all 5 required spread
fields are filled: `option_spread_type`, `option_expiry`, `option_long_strike`,
`option_short_strike`, `entry_price`.

**Structure (3 sub-states):**

```
[advisory panel container]        ← background: var(--surface2), borderRadius: 8,
                                     padding: '10px 12px', display: flex, flexDirection: column, gap: 8

  [header row]                    ← display: flex, justifyContent: space-between, alignItems: center
    [label]  "AI ADVISORY"        ← fontSize: 11, fontWeight: 700, color: var(--accent),
                                     textTransform: uppercase, letterSpacing: 0.05em
    [button] "Get Advisory"       ← see button spec below

  [content area]                  ← one of 3 states:
    STATE idle:     nothing rendered (no copy, no placeholder)
    STATE loading:  spinner + "Evaluating spread…" text
    STATE result:   advisory prose (fontSize: 13, var(--text2), lineHeight: 1.5)
    STATE error:    error message (fontSize: 13, var(--red))
```

**"Get Advisory" button spec:**
- Reuse `.btn-sm` class with inline overrides for state
- Enabled (fields filled, not loading):
  `border: 1px solid var(--accent)`, `color: var(--accent)`, `fontSize: 11`,
  `padding: '4px 10px'`, `borderRadius: 5`, `background: transparent`, `cursor: pointer`
- Disabled (fields incomplete):
  same as above but `opacity: 0.4`, `cursor: not-allowed`
- Loading state: button hidden; spinner shown instead
- After result: button label changes to "Refresh Advisory", same style as enabled

**Loading spinner:** A single `<div>` with `width: 14, height: 14, borderRadius: '50%',
border: '2px solid var(--border2)', borderTopColor: 'var(--accent)',
animation: 'spin 0.7s linear infinite'`. Add `@keyframes spin` to globals.css if not
present. Inline with "Evaluating spread…" text at `fontSize: 13, color: var(--muted)`.

**Advisory result display:**
- Container: same `.drill-explanation` pattern — `background: var(--surface2)`,
  `border: 1px solid var(--border2)`, `borderRadius: 8`, `padding: 16px`,
  `display: flex`, `flexDirection: column`, `gap: 8`
- No heading inside the result block (the panel header already says "AI ADVISORY")
- Advisory prose: `fontSize: 13`, `color: var(--text2)`, `lineHeight: 1.5`
- Max 200 words rendered as a single `<p>` — no truncation

**Error state:**
- Replace result area with: `fontSize: 13, color: var(--red)`
- Copy: "Advisory unavailable. Check your connection and try again."

**State stored in component:** `advisoryState: 'idle' | 'loading' | 'result' | 'error'`
and `advisoryText: string`. These are local state variables, not form state.

**Pre_trade_advisory submission:** When user clicks "Open Trade", if `advisoryText` is
non-empty, include it in the submitted payload as `pre_trade_advisory: advisoryText`.
If advisory was never fetched (idle/error), submit `pre_trade_advisory: null`.

## Interaction Contracts

### Advisory Panel — Interaction Flow

```
User selects "Option Spread" trade type
  → Advisory panel appears (idle state, button disabled)

User fills: spread type, expiry, long strike, short strike, premium
  → Button enables ("Get Advisory")

User clicks "Get Advisory"
  → Button hides, spinner + "Evaluating spread…" appears
  → POST /api/trades/spread-advisory with current form values
  → On success (< 10s typical): show advisory text (result state)
  → On error / timeout: show error copy (error state), button re-enables

User edits any spread field after advisory is shown
  → Advisory result is cleared, state resets to idle
  → Button re-enables with label "Get Advisory"

User clicks "Open Trade"
  → advisoryText included in payload if non-empty
  → No confirmation dialog — advisory is advisory, not a blocker
```

### Advisory — Fields Required Gate

The button transitions from disabled → enabled ONLY when ALL of these are truthy:
- `form.option_spread_type` (non-empty string)
- `form.option_expiry` (non-empty string)
- `form.option_long_strike` (numeric, > 0)
- `form.option_short_strike` (numeric, > 0)
- `form.entry_price` (numeric, > 0)

This is a UI-only gate (same logic as `validate()` but non-blocking).

### Drill — No New Interactions

Train page interaction is unchanged. `options_setups` uses `QuizDrill` component
(same as `setup_selection`, `entry_timing`, etc.) because `type` is not `"risk_calc"`.

## Accessibility Contracts

- "Get Advisory" button must have `aria-disabled="true"` when fields are incomplete
  (not just `disabled` attribute, since disabled buttons skip tab focus in some
  browsers — this matters for the drawer's keyboard flow)
- Advisory result `<p>` should have `role="status"` so screen readers announce new
  content when advisory loads
- Loading spinner `<div>` should have `aria-label="Loading advisory"` and
  `aria-live="polite"` on the container
- Drill question options already handle focus via the existing `QuizDrill` component —
  no changes needed

**Pattern to follow for advisory result prose:**

`color: var(--text2)`, `lineHeight: 1.5`.

**State variable names (suggested):**
```js
const [advisoryState, setAdvisoryState] = useState('idle') // 'idle'|'loading'|'result'|'error'
const [advisoryText, setAdvisoryText]   = useState('')
```

Reset advisory state when any spread field changes:
```js
function set(key, val) {
  setForm(f => ({ ...f, [key]: val }))
  setErrors(e => ({ ...e, [key]: undefined }))
  if (['option_spread_type','option_expiry','option_long_strike',
       'option_short_strike','entry_price'].includes(key)) {
    setAdvisoryState('idle')
    setAdvisoryText('')
  }
}
```
