<objective>
Extend the existing `generate_trade_debrief` function so the post-trade behavioral debrief references the pre-trade advisory when one is present. This closes the feedback loop: Claude evaluates the plan before the trade (Plan 02/03), then compares plan vs. execution after the trade closes.

Purpose: Per CONTEXT D-04, this is a minimal extension — no structural changes to the existing 4-paragraph spread debrief, just one extra context line in the trade block and one extra instruction at the end of the prompt when `trade.pre_trade_advisory` is non-empty.

Output: A small, surgical patch to `generate_trade_debrief` plus tests that assert the advisory text reaches Claude's prompt input.
</objective>

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-04-01 | Tampering / Prompt Injection | Advisory text concatenated into Claude prompt | accept | Both the advisory and the surrounding prompt come from the same authenticated user. Worst case: user injects instructions into their own debrief — no cross-user impact and no privileged action available to Claude. Same trust model as the existing `pre_note` concatenation at line 110 |
| T-07-04-02 | Information Disclosure | Outbound Claude payload now includes advisory text | accept | Equivalent exposure to existing `pre_note` field already sent in the same prompt. No new third-party recipient. Anthropic API contract is unchanged |
| T-07-04-03 | Denial of Service | Larger prompt size | mitigate | Advisory is capped at < 200 words by Plan 02 (`max_tokens=300` on the generating call). Even a maxed-out advisory adds at most ~1.2 KB to the debrief prompt. `max_tokens=500` for the debrief call is unchanged. No risk of token overflow |
| T-07-04-04 | Repudiation | Audit of which advisory was referenced | accept | The advisory and final ai_debrief are both persisted on the same `trades` row. The pairing is implicit but recoverable. Logging the prompt is not added; sufficient for solo-user app |
| T-07-04-SC | Tampering | npm/pip/cargo installs | mitigate | No new package installs. `anthropic` already in `requirements.txt`. Tests import the new private helper directly — no test-time dependencies added |
