## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser → `POST /api/trades/spread-advisory` | User-entered spread parameters cross to backend; backend already validates (Plan 02) |
| browser → `POST /api/trades/` | `pre_trade_advisory` string from frontend persists to DB |
| advisory text → React render tree | Returned advisory string is rendered as text content in a `<p>` |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-03-01 | Tampering / Cross-Site Scripting | Advisory text render | mitigate | React JSX text content is auto-escaped. Advisory is rendered with `{advisoryText}` (not `dangerouslySetInnerHTML`). `whiteSpace: 'pre-wrap'` only affects rendering of literal whitespace, not HTML interpretation |
| T-07-03-02 | Information Disclosure | Advisory persisted to local DB | accept | Inherited from Plan 02 (`pre_trade_advisory` scoped to `user_id`). Frontend only displays trades owned by the authenticated session |
| T-07-03-03 | Denial of Service | Repeated `Get Advisory` clicks | mitigate | Button hides during `'loading'` state, preventing concurrent in-flight requests for the same drawer instance. The advisoryState transition guards the click handler |
| T-07-03-04 | Tampering | `pre_trade_advisory` submission tampering | accept | Backend trusts the client to supply its own advisory string; this is by design (user may edit, paste, or not fetch one). Threat is low because the field is per-user, per-trade, and has no privileged effect |
| T-07-03-05 | Spoofing / Accessibility regression | Disabled button skipping focus | mitigate | Per UI-SPEC line 283–285, the button uses both `disabled` and `aria-disabled="true"` so screen readers announce the disabled state even when the disabled attribute would skip tab focus |
| T-07-03-SC | Tampering | npm/pip/cargo installs | mitigate | No new packages added. No `npm install` is part of this plan. `node`/`npm` invocations only run `npm run build` against the existing `package.json`.
