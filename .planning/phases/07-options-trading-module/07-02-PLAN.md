<objective>
Add the pre-trade spread advisory backend: a new `pre_trade_advisory` column on `Trade`, the Claude advisory service function, and the `POST /api/trades/spread-advisory` endpoint that returns advisory text without persisting a trade. Also wire `pre_trade_advisory` through `TradeCreate`/`TradeResponse` so the open-trade flow can store the advisory the user accepted.

Purpose: Per CONTEXT D-02, before opening a credit spread the user wants Claude's evaluation of strike placement, risk/reward, and expectations. Storing the advisory text alongside the trade then lets the post-trade debrief (Plan 04) compare plan vs. execution.

Output: Migrated DB, new endpoint live, and pytest coverage proving advisory shape, validation, and persistence without depending on a live Anthropic key.
</objective>
