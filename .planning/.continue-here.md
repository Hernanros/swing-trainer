<decisions_made>

- **Architecture: Approach B** (pre-filter screener + Claude Haiku batch) chosen over agentic approach C — better latency, lower cost, same Claude patterns as existing codebase
- **Options data: yfinance** (free, no API key) as default provider. `TradierOptionsProvider` stub in `backend/services/options.py` — swap by adding `TRADIER_API_KEY` env var
- **Universe: S&P 500 (~450 symbols)** hardcoded as `SP500_UNIVERSE` constant in `backend/services/bull.py`
- **Scheduler: APScheduler AsyncIOScheduler** in FastAPI lifespan — runs at 5 PM ET Mon-Fri, skips US market holidays (hardcoded 2026 list)
- **Data: EOD closing data** from TwelveData daily time series — not real-time
- **UI layout: top-down stack** — macro bar → sector strip → candidates table → chat (user selected option A in visual companion)
- **Scoring: Claude Haiku** for batch scoring (5 dimensions, 0-10), **Claude Sonnet** for chat follow-ups
- **Position sizing: server-side computation** using saved bull_profile (account_size, risk_per_trade_pct, max_contracts)
- **IV proxy**: yfinance gives ATM implied volatility, not true IVR — displayed as "IV%" in UI until Tradier provides proper IVR
</decisions_made>
